================================================
  宿泊税計算システム — Windows セットアップ手順
================================================

【ステップ1】Python のインストール確認
─────────────────────────────
1. キーボードの「Windows キー + R」を押す
2. 「ファイル名を指定して実行」に「cmd」と入力して Enter
3. 黒い画面（コマンドプロンプト）が開いたら以下を入力

   python --version

4. 「Python 3.x.x」と表示されれば ステップ2 へ進む
   エラーが出た場合は以下の手順でインストールしてください


【ステップ1-A】Python のインストール（未インストールの場合）
─────────────────────────────
1. Microsoft Edge または Chrome で以下のURLを開く
   https://www.python.org/downloads/windows/

2. 「Python 3.x.x」（最新版）の「Download Windows installer (64-bit)」
   をクリック

3. ダウンロードされた「python-3.xx.x-amd64.exe」をダブルクリック

4. ★★ 重要 ★★
   インストーラーの最初の画面で
   「Add Python 3.x to PATH」に必ずチェックを入れる

5. 「Install Now」をクリック
   ※「このアプリがデバイスに変更を加えることを許可しますか？」
     → 「はい」をクリック

6. 「Setup was successful」が表示されたら「Close」をクリック

7. コマンドプロンプトを一度閉じて開き直し、以下で確認
   python --version
   → 「Python 3.x.x」と表示されれば OK

   ★ まだエラーが出る場合
   「python3 --version」でも試してください。
   それでもエラーの場合は PC を再起動してから再確認してください。


【ステップ2】アプリのセットアップ
─────────────────────────────
1. ZIPファイルを解凍してフォルダを開く

2. 「setup.bat」をダブルクリック
   ※「WindowsによってPCが保護されました」と出た場合は
     「詳細情報」→「実行」をクリック

3. 黒い画面が開き、自動でパッケージがインストールされます
   （初回は1〜3分かかります）

4. 「セットアップ完了！」と表示されたら「Enter キー」で閉じる


【ステップ3】アプリの起動
─────────────────────────────
1. 「launch.bat」をダブルクリック
   ※ 同様に「詳細情報」→「実行」が必要な場合があります

2. 黒い画面が開き、数秒後にブラウザが自動起動します

3. アドレスバーに「http://localhost:8501」と表示されれば OK

4. 終了するときは黒い画面（コマンドプロンプト）を × で閉じる


【よくあるトラブル】
─────────────────────────────
Q. ブラウザが自動で開かない
A. Edge または Chrome で「http://localhost:8501」を手動で開く

Q. 「python は内部コマンドまたは外部コマンド...ではありません」
A. Python インストール時に「Add Python to PATH」の
   チェックが入っていなかった可能性があります。
   Python を一度アンインストールし、チェックを入れて再インストール
   するか、以下を試してください：
   「py --version」と入力して確認

Q. 「WindowsDefender ファイアウォール」の警告が出る
A. 「プライベートネットワーク」にチェックが入っていることを
   確認して「アクセスを許可する」をクリック（ローカル専用なので安全）

Q. ポートが使用中というエラーが出る
A. launch.bat をメモ帳で開き
   「--server.port 8501」の数字を 8502 などに変更して保存
