================================================
  宿泊税計算システム — 使い方
================================================

【初回のみ：セットアップ】
1. setup.command を右クリック →「開く」をクリック
   ※「開発元を確認できません」と表示された場合も「開く」を選択
2. ターミナルが開き、自動でパッケージがインストールされます
3. 「セットアップ完了！」と表示されたら Enter キーで閉じます

【毎回の起動】
1. launch.command をダブルクリック（または右クリック→「開く」）
2. ブラウザが自動的に開き、アプリが表示されます
3. アプリを終了するときはターミナルウィンドウを閉じてください

【注意事項】
- インターネット接続がなくても動作します
- ポート 8501 を使用します（他のアプリと競合する場合はお知らせください）
- 生成された Excel ファイルは任意の場所に保存してください
